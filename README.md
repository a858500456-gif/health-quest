# 健康小知識讀書站

把「LLM Wiki:健康小知識」整理成可以瀏覽與自我測驗的靜態網站。7 章、37 題;每個重點都標示來源與日期,並誠實列出資料限制。

- 網站:https://a858500456-gif.github.io/health-quest/
- 專案規則:[AGENTS.md](AGENTS.md)(AI 繼續製作新章節時要遵守的規則)

## 本機瀏覽
直接用瀏覽器開啟 `index.html` 即可(純靜態,無需安裝)。

## 新增章節
照 [AGENTS.md](AGENTS.md) 第 8 節:複製一個章節檔 → 改寫 → 在 `index.html` 加一行 script → 跑檢查清單。
